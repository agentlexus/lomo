# Постпроцессор FT1000-5axis(AC)

Памятка по проделанной работе: что было, что сделано, как воспроизвести.

## Назначение

5-осевой фрезерный станок FT1000 (кинематика `5_axis_head_table`: 4-я ось A — голова,
5-я ось C — стол). Стойка — **FANUC 30i advanced**. Пост — NX Post Builder
(файлы `.tcl` / `.def` / `.pui` / `.cdl`).

## Структура проекта

| Путь | Назначение |
|---|---|
| `Original\original_encripted\` | **Оригинал** — зашифрованный (обфусцированный) пост от вендора (25.09.2026) |
| `Original\original_no_oper_number\` | Читаемая версия без нумерации (`_noseq`), не трогалась |
| `Original\original_zip\` | Исходные архивы от вендора |
| `Decoded\` | Наша рабочая папка: декодированный и патченный пост |
| `working_script\` | Скрипты декодирования и правок (байтовые, идемпотентные) |
| `nc\` | Тестовые УП: эталон и результат с нумерацией |

## Исходное состояние и обфускация

`Original\original_encripted\FT1000-5axis(AC).tcl` был **обфусцирован**: весь код поста лежит внутри
самодекодирующегося загрузчика:

```tcl
proc _yfacabd {d k1 k2} { ... }              ;# декодер
set xdabbee [binary format c* { ...2.1 МБ чисел... }]
eval [_yfacabd $xdabbee 0x5A 0xA5]           ;# «расшифровать и выполнить»
```

Преобразование — **циклический сдвиг + XOR** (это защита от копирования, а не шифрование):

```
decoded = ROR2(byte) XOR (0x5A ^ 0xA5) = ROR2(byte) XOR 0xFF
encoded = ROL2(decoded XOR 0xFF)             ;# обратная операция
```

## Что было сделано

### 1. Декодирование
Скрипт `working_script\decode.py` вытаскивает числа между `binary format c* {` и `}]`,
применяет формулу выше и кладёт читаемый `.tcl` + копии `.def/.pui/.cdl` в `Decoded\`.

- Декодированный `.tcl` — **UTF-8, перевод строк LF**; размер 562 462 Б, 16 889 строк.
- Оригинальный `.tcl` при этом не изменялся.

### 2. Включение нумерации кадров (вариант B)
Задача: **N на каждый кадр программы**, при этом маркер операции и шапка должны
показывать **реальный номер строки** (совпадать с телом).

Исходно пост выводил номер только на строке-маркере `N{n};(Operation: …)` через ручной
счётчик `g_op_seq_counter`, а встроенная нумерация Post Builder была **выключена**
(поэтому в шапке были порядковые `N1..N24`, а кадры — без N).

Решение — перевести всё на встроенный счётчик `mom_seqnum` (одна серия номеров):

| # | Процедура | Правка |
|---|---|---|
| 1 | `MOM_first_move`, `MOM_initial_move` | `MOM_set_seq_off` → `MOM_set_seq_on` |
| 2 | `MOM_first_tool` | `MOM_set_seq_off` → `MOM_set_seq_on` |
| 3 | `MOM_start_of_path` | концевой `off` → `on` (тело операции нумеруется); маркер выводится при включённой нумерации |
| 4 | `PB_auto_tool_change` | `on` включается после комментария `(Tool Change)` |
| 5 | `PB_CMD_path_info` | раскомментирован `MOM_set_seq_on` (иначе нумерация «гасла» навсегда) |
| 6 | комментарии `(start of Path)`, `(Tool Change)`, `(End of Program)`, `(End of Path)`, `(Initial tool)` | обёрнуты `off/on`, чтобы остались без `N` |
| 7 | `PB_CMD_output_op_marker` | `set g_op_seq_counter [expr {int($mom_seqnum)}]`; из строки убран ручной `N…` (движок ставит N сам) |

Правки делает `working_script\enable_seqnum.py` (байтово, с `assert` на число вхождений,
по якорям). Он же **кодирует обратно** в защищённый вид (та же обёртка `_yfacabd`).

### 3. Сборка и деплой в NX
Результат — отдельный пост **`FT1000-5axis(AC)_N`** (чтобы отличался от оригинала):

- Папка `D:\Programs\NX2312\MACH\resource\postprocessor\FT1000-5axis(AC)_N\`:
  `FT1000-5axis(AC)_N.{tcl,def,pui,cdl}` (в `.pui` ссылки обновлены на `_N`).
- В `template_post.dat` добавлена запись `FT1000-5axis(AC)_N`.
- Оригинал возвращён под именем `FT1000-5axis(AC)` в свою папку.

## Проверка (на реальной УП)

Тестовые УП в `nc\`:

| Файл | Что это |
|---|---|
| `seq_off_original.nc` | эталон — оригинальный пост (без нумерации) |
| `seq_on.nc` | наш пост `_N` (с нумерацией) |

Результат сравнения:

- тело программы (от `O0001`, **1350 строк**) после снятия N-префиксов — **0 расхождений**:
  координаты X/Y/Z/A/C, G/M-коды, циклы, подходы, смены инструмента идентичны;
- в шапке OPERATION LIST — целые `N2, N31, N47, …` (без `.0`);
- номера в шапке **совпадают** со строками-маркерами `N<n> ;(Operation: …)` (24/24);
- `%`, `O…`, комментарии `;(…)` — без N.

## Как повторить / изменить

```powershell
# 1. декодировать (читаемая копия в Decoded\)
python "FT1000-5axis(AC)\working_script\decode.py"

# 2. внести правки и собрать защищённый файл
#    (редактируется только enable_seqnum.py)
python "FT1000-5axis(AC)\working_script\enable_seqnum.py"
```

Скрипты работают от pristine-копии (`Decoded\FT1000-5axis(AC).tcl`) — повторный запуск
идемпотентен.

## Известные нюансы

1. **Форма файла.** Задеплоенный `_N.tcl` — защищённый (обфусцированный). Post Builder
   не читает из него кастомные команды; для правок используйте читаемую
   `Decoded\FT1000-5axis(AC)_seqnum.tcl`.
2. **Пробел в маркере.** Движок выводит `N2 ;(Operation: …)` (с пробелом) вместо
   оригинального `N1;(Operation: …)` — это разделитель слов при встроенной нумерации.
   На работу не влияет.
3. **Кодировки.** Декодированный `.tcl` — UTF-8/LF; защищённая обёртка — CRLF
   (сохраняется при пере-кодировании). Китайские комментарии — UTF-8.
